## 8. 与设计文档的偏离与调和

唯一偏离来自 `docs/11` §3.4 ⑥ 的一个**事实性假设**：该处要求「复用 L313-325 已存在的 7 页遍历循环，在按钮对比度 `c.eval` 里搭车采样 `--key`」，隐含假设「7 页都有主按钮」。实测（`git` 工作树 + 浏览器）：`settings.html` / `history.html` / `about.html` 三个工具子页**没有 `.btn-solid` / `.btn-grad`**，原 `if(!b) return null` 使 `btnRatios` 只收到 4 页，新增断言 `new Set(pageKeys).size===7` 必然 FAIL（首轮 E2E 61/62 复现）。

**调和方式（最小改动 + 加严 + 保护基线）**：把该 `c.eval` 改为「无按钮页仍创建临时元素解析本页 `--key` 并返回，`ratio` 置 `null`」，使 7 页全部进入采样；`badBtn` 过滤改为 `r.ratio !== null && r.ratio < 4.5`（与 v0.18「只有有按钮的页参与按钮对比度判定」语义完全一致，断言主体 `badBtn.length===0` 一字未改）；新增断言额外加 `pageKeys.length===7` 防止将来漏采样。修复后 **62/62**，7 页 chroma 全部打印且 >0.45。此为加严而非放宽阈值，符合主理人「禁止放宽阈值假通过」要求。

其余实现均按 `docs/11` §7 的 T01 → T05 顺序完成，PRD §6 的 10 项与设计 §9 的 10 项全部采纳默认；无其他偏离，无回退 v0.17，未引入任何外部依赖 / 字体 / 图标 / 动效库。
