## 3. 信息结构

```
屏幕工具条（no-print）  REPORT / 任务 ID · 打印输出 5 个附录      [导出 PDF（打印）]
卷首签发带              SECURITY ASSESSMENT REPORT / 探测报告 / 任务 ID
                        右：终态形状章（已检出 / 未检出 / 降级命中 / 纯模拟 / 异常 / 已取消）
                        3 读数：执行轮次 3/8 · 累计耗时 4250 ms · 降级轮次 0
01 封面信息             6 项事实格 + 越界告警（如有）+ 合规声明
02 执行摘要             结论句 + 8 格轮次预算刻度 + 2 条要点（降级轮 / 适用范围）
03 附录 A 逐轮记录      8 列表，响应分类用形状标签，命中行整行标记
04 附录 B 模型原文      N 条逐轮 JSON，导出前自动展开
05 附录 C 配置快照      8 项事实格
卷尾水印                任务 ID · 演示数据 · 非实时推理 · 零外部请求 · 本地契约桩生成
```

**5 个 `.report-sec` 的编号、顺序、数量与打印 `break-inside:avoid` 全部保留**（既有验收契约）。
亮色只作填充：签发章按状态语义取色（命中青 / 降级琥珀 / 越界·未检出告警红），
编号徽标沿用 report 页主色珊瑚 `#ff6b6b`；文字与描边一律深语义色。

## 4. 数据契约：一行都不编造

- 结论形状与文案来自 `resolveTerminalState(r)`（`out_of_scope → MAX_ROUNDS → HIT+降级 → HIT → error` 的唯一语义入口），
  不是按 `terminate_reason` 另写一套判断。
- 3 个读数分别取 `r.rounds.length / max_rounds`、`r.elapsed_ms`、`r.degraded_rounds.length`；
  注解「未使用 N 轮预算」「逐轮 cost_ms 之和」「已单列，不计入主指标」均可由 report 核对。
- 8 格刻度按 `r.rounds` 逐轮生成（`data-cls` / `is-deg` / 命中格 / 空槽），剩余补到 `task.max_rounds`。
- 逐轮表、JSON 原文、封面 6 项、附录 C 8 项全部沿用原字段，统一走 `esc()`。
- 删掉「第 1 / 1 页」，换成可核对的零外部请求声明。

**保持不动的行为**：`#reportCard .report-sec` = 5、`#exportBtn` 仍由 `renderReport` 动态注入（静态 HTML 无该 id）、
`exportBtn.onclick` 展开 `details.raw` 后 `window.print()`、`#reportEmpty / #reportCardWrap / #reportCardLoading`、
`Store.getReport()` 恢复、零外部请求、`file://` 可运行、reduced-motion 全降级。

**新增**：`bootReport()` 注册 `beforeprint`，浏览器菜单 / `Ctrl+P` 直接打印也会展开 JSON 附录，
不再只能点导出按钮。

## 5. 样式与打印规格

- 第 12 段整段重写：`.rpt-*` 前缀；删掉不再使用的 `.cover` 三规则（同步清掉 700px 媒体块里的引用）；
  新增签发带、事实格、编号刻度尺、轮次预算刻度、空态；`:root` token 零增删。
- 4px 栅格：卡内 24、事实格 14/16、模块间距 28、刻度 30 高；字号全部 ≥11px，最小 11px（修掉旧 10px）。
- 打印第 18 段：卡片 / 表头 / 所有 td / tag 变体 / 签发章 / 命中格统一白底黑字；
  表格字号 10px → **11px**；命中格在黑白下改用 **2px 粗框** 与「1px 细框 + 横杠」的拦截格区分，
  形状编码不依赖颜色。5 附录不变，导出按钮与导航仍隐藏。
- 响应式：1100 以下附录 C 事实格 4 列 → 2 列；700 以下签发带换列、3 读数竖排、事实格 1 列、
  编号徽标缩到 18px、工具条与空态列表换行。

## 7. 已知边界

- 附录 B 屏幕上仍是可折叠 `<details>`（内容较长，默认收起）；导出与 `Ctrl+P` 都会自动展开。
- 报告只回显会话内最近一次任务（`sessionStorage` 语义），刷新浏览器即回到空态；多条记录在历史页。
- 签发章形状与 8 态状态机一致；`cancel` 与 `error` 共用叉号，靠中文文案区分。
