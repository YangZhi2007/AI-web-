# 13 · 配置中心重设计说明（v0.20.0）

> 范围：`webapp/settings.html`（原「配置快照」子页面）整体重做 + `css/console.css` 新增 `.cfg-*` 段 +
> `js/app.js` 的 `bootSettings()` 重写与 `bootConsole()` 预填 + `js/console.js` 的 `Store` 增量方法。
> 其余 6 个功能页只改了一个属性：顶栏配置入口的 `aria-label/title` 由「配置快照」改为「配置中心」。

---

## 1. 为什么要重做

原页面只有两块内容：一张 6 行只读参数表（`#cfgContract / #cfgMode / #cfgMax / #cfgTick / #cfgAdapter / #cfgRuleset`）和一张三剧本说明卡。
它有三个问题：

1. **不构成"配置页"**：没有任何可操作项，答辩现场无法演示"改一个参数 → 影响下一次任务"。
2. **值和真值可能漂移**：六个字段里 `MOCK` / `LAB-RULESET-01` / `1.0` 是写死在 `app.js` 里的字面量，与引擎真实导出的 `CONFIG` 无关联，改引擎时会静默不一致。
3. **信息密度低**：三套剧本、8 个终态、越界白名单这些真正需要被评审看见的契约信息，一页里都没有。

重做的目标是把它变成**配置中心**：一条"可改 / 不可改"的分界线，加上引擎契约的可视化投影。

## 2. 方向（五要素）

| 项 | 结论 |
|---|---|
| 产品 | 一个离线运行的本地演示控制台，用固定剧本展示自适应探测如何逐轮收敛或失败，给论文答辩的评审看 |
| 性格 | 精确、仪表感、克制的活泼 |
| 世界 | 实验台 / 仪表盘：刻度、丝印标签、读数窗、校准板——底色是浅酸柠纸白，不是深色机柜 |
| 记忆点 | ① 剧本库里那条"8 格轮次预算"刻度：早停的剧本右侧留空槽，一眼看出用了几轮；② 8 个终态的形状编码板 |
| 签名细节 | 每行左端 2×14px 的刻度条——失焦时是发丝灰，聚焦转深墨，与已保存值不一致时亮酸柠（未保存信号） |

## 3. 信息结构（5 个模块 + 1 条读数带）

```
读数带（4 格）  ENGINE mock · MAX ROUNDS 8 · TICK demo · SCENARIOS 3
01 下一次任务默认值    目标地址 / 漏洞类型 / 演示剧本 + 保存 · 恢复出厂 · 带到任务台
02 边界与契约          授权范围白名单（chips）+ 5 条冻结常量
03 演示剧本库          3 张卡，每张 8 格轮次刻度（横杠=拦截 实心=异常命中 虚线框=降级轮 空槽=未使用轮次）
04 终态判定            判定优先级 + 8 态（形状 / 代码 / 中文 / 触发条件）
05 最近一次任务        只读回显 cfg 快照 + 报告终态，附「去任务台 / 查看报告」
```

栅格节奏：读数带（4 等分）→ `1.55fr : 1fr`（01 宽 + 02 窄）→ 全宽三等分（03）→ `1.45fr : 1fr`（04 + 05）。
1100px 以下全部收成单列，剧本卡改为整行"账本行"，避免三卡变两卡再留一张孤卡。

## 4. 交互与数据来源（一行都不能是假的）

| 交互 | 实际行为 | 数据来源 |
|---|---|---|
| 保存默认值 | 校验 `^https?://` → 写 `Store.setDefaults()`；失败只报错不写 | 表单当前值 |
| 恢复出厂 | `Store.clearDefaults()` + 表单回填出厂值 | 常量 `FACTORY` |
| 带到任务台 | 先执行保存，再经 `#cfgNav[data-nav]` 走圆形揭幕翻页 | — |
| 载入到 01（剧本卡） | 只改 01 的剧本下拉 + 高亮卡片，需再保存才生效 | `Probe.SCRIPTS` |
| 待改刻度 | 当前值 ≠ 已保存默认值（无保存则对比出厂值）时点亮 | 同上 |
| 去任务台 / 查看报告 | 只读回显，无副作用 | `Store.getCfg/getReport` |

**关键约束（沿用 v0.17.2 的意图模型）**：配置页**从不**写 `probe.pendingRun`。
保存 / 恢复出厂 / 载入剧本 / 带到任务台四个动作，实测 `sessionStorage['probe.pendingRun']` 始终为空，
`probe.history` 条数不变——即"改配置不会产生任务"。执行入口仍然只有一个：任务台勾选授权后点击「开始分析」。

任务台侧只做**预填**：`bootConsole()` 读 `Store.getDefaults()` 覆写 `#urlInput / #typeSel / #scriptSel` 的初始值，
不勾选授权、不置位意图；无保存值时保持 HTML 出厂值（实测回落到 `http://127.0.0.1/lab/sqli_01.php` / `sqli` / `CONVERGE_3`）。

**"不可改"的部分照实说**：`ENGINE_MODE / MAX_ROUNDS / TICK_SPEED / API_BASE_URL` 是 `console.js` 顶部
`Object.freeze` 的编译期常量，页面把它们放在 02「冻结常量」里只读投影，并写明"改档需改代码，页面不提供写入"，
不提供假开关。

## 5. 样式规格（只加不改）

- 全部新增规则以 `.cfg-*` 前缀、只服务 settings 页；`:root` **未新增、未删除、未改名任何 token**。
- 复用现有语义色：`--key`（settings 页 `#A9DF3C`）、`--t-1/2/3`、`--n-*` 表面、`--sit-*` 与 `--dot-*`。
  亮色只作填充（配 `--accent-ink` 深墨字），文字/描边一律用同色相深版，保 ≥4.5:1。
- 4px 栅格：行 padding 16 / 卡 padding 20–24 / 模块间距 20–32 / 圆角 12（卡）· 8（内层）· pill（编号徽标）。
- 字号：正文 12–13，标签 11（全站正文级最小 11px 不变）；读数与终态代码用 `--mono`，KPI 用 `--display` 26px。
- 动效只用 `color/background/border-color/transform`，时长沿用 `--d-inst 160ms / --d-step 220ms`；
  无循环动画、无渐变文字、无发光堆叠、无 emoji。
- `prefers-reduced-motion` 由既有全局块统一关闭，新增元素不依赖动画传达信息。

## 7. 已知边界（不做假）

- 页面不提供 `TICK_SPEED / MAX_ROUNDS` 的写入：它们是冻结常量，做假开关比不做更糟。
- 05「最近一次任务」只显示会话内最近一次（`sessionStorage` 语义），刷新浏览器即空；历史多条请看历史页。
- 「带到任务台」会先保存默认值（避免用户改完直接跳走丢失），提示文案已写明"保存后生效"。
