### 2. 向组长确认三件事（阻塞项）

### 3. 部署机联调（拿到上面之后）

```bash

# 建任务（TARGET_URL 由编排层从靶址注入，DJ_PYTHON 确保子进程用对解释器）
curl -X POST http://localhost:8000/api/scan.php \
  -H 'Content-Type: application/json' \
  -d '{"target":"http://192.168.109.129/shop_labs","authorization_id":"<授权编号>"}'

# 浏览器打开展示页，一键执行，看六阶段流水线与双轨报告
```

真实靶场下不设 `DJ_MOCK`，产物 `evidence.json` 即真实证据链。

## 一条诚信红线（联调时最容易松）

`oracle` / `verdict` 必须由靶机响应裁决，不能让模型回填 `validation:PASSED` 自证。
`verify.py` 已把这条固化：改 `reason`/`confidence` 不影响裁决、异常一律 `error`、
未知类型不猜 `confirmed`。对接 `head.py` 时不要为了"让报告好看"绕过它。
