# 26 · 幻觉修复页 unslop 精炼说明（v0.31）

## 一、这次做了什么

用 unslop 技能对 v0.30 刚开发完的幻觉修复 5 个页面做精炼。延续已确立的**方向 A（保留高饱和基因做精炼）**，polish 模式：不动调色板、布局骨架、功能与引擎，只修审计发现的真问题。

| 页面 | 真问题（unslop sign） | 修法 |

## 三、方向与 signature

- **Product**：无训练条件下的幻觉修复实验台——判定独立、RAG 替代微调、验证集真实对比
- **Character**：精确、克制、有检定记录感
- **World**：对照实验台 / 校准记录本——每个结论都成对出现
- **Moments**：评测页 base→RAG 对照柱（唯一 rich 图表）、探测页双条件逐题判定表
- **Signature**：**双轨对照**——每个样本、每张图都成对呈现（base 灰 / RAG 绿）。本轮把它做到样本收起态，成为一眼可读的产品指纹

保留的基因：高饱和亮底、酸柠强调、句首大写标签、8 态形状编码、单一亮元素、refine.css 全页精炼成果。

## 四、过程中修的真 bug

总览页没引入 `css/hf-app.css`，导致分组样式与跨列标签完全没生效（截图里标签和卡片挤在同一行）。用 CDP dump `getComputedStyle(...).gridColumn` 发现是 `auto` 而非 `1 / -1`，定位到缺 link。补引入后分组正常。
