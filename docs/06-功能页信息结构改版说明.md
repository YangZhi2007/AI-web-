## 3. 保留 / 修改 / 移除清单

### 3.1 保留（业务目标与数据逻辑，一项未动）
- `console.js` 全部逻辑：`CONFIG`(freeze)、`RUNTIME`、`SCRIPTS` 三剧本、`MockEngine` / `HttpEngine` / `AnalysisEngine`、
  `esc` / `displayUrl` / `scopeOK` / `paintBars` / `paintRail` / `scramble` / `switchTab` / `setMsg` / `syncStart` 等。
- 59 个静态 DOM id + 动态 `exportBtn`；全部 `data-*` / `aria-*` 契约、`role="status"`、`tabindex`。
- MockEngine 三剧本与终止原因（HIT / MAX_ROUNDS）、越界诚信标注 `OOS_NOTICE`、`mock_flag` 全链路、
  报告水印与 PDF 导出、授权闸门、SSE 接口桩（`api.js` 6 个）、`prefers-reduced-motion` 降级。
- 仪表台（主读数 + 刻度轨 + 发丝线矩阵）、run-panel 运行态、terminal 日志、打印样式。
- `SOUND OFF` 开关（JS 绑定，保留但保留原有弱化呈现）。

### 3.2 修改
- 页头结构（巨型 Hero → 紧凑两栏 + 合规卡）、标题文案与字号。
- 5 个主区块增加阶段头；导航文案 `1.0 探测…` → `01 概览…`（href 与 id 不变，`IntersectionObserver` 契约保持）。
- 空态、消息反馈、授权提示的结构与文案。
- 配色明度（§4）、响应式（页头单栏、阶段头换行、导航独占整行）、打印隐藏规则（新增装饰不进报告）。
- 页脚链接与合规文案。

### 3.3 移除
- 页脚 4 个指向 `#settings` 的死链（`03 §5 S-5`）。
- 页脚「界面参照 app.soul.io 应用」「设计参考 / DESIGN REFERENCE」两条与业务口径无关的声明
  （head 注释中的设计借鉴声明**保留**，属主动透明，不影响业务口径）。
- 窄屏顶栏重复的状态装饰 `.net`（同口径已由页头合规卡承载）；仅 `≤700px` 隐藏，桌面保留。
- 巨型 Hero 的视觉权重（不是删内容，是降层级）。

> **未引入任何新功能**：没有新增按钮、输入、数据源、交互事件或 JS 逻辑；所有新增元素均为静态展示与样式容器。
