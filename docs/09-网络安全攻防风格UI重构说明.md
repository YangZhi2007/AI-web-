# 09 · 功能页 UI 重构说明（v0.18「SOC 攻防仪表」）

> 版本基线：`v0.17.2`（`a1d43ab` / `d3cddee`）· 本次交付：`v0.18.0`
> 依据：评审反馈「当前偏卡通 → 改为具备科技感的网络安全攻防风格」
> 方法：`@skill:unslop` 的九遍 redline pass（间距 → 颜色 → 图标 → 文案 → 字号 → 布局 → 细节 → 视觉 → 动效）
> 交付物：完整可运行页面实现代码 + 改动对照说明 + 视觉规格说明 + 交互状态说明（本篇 §3 / §4 / §5）

---

## 0. 一句话结论

功能页从「暖白纸底 + 每页一色高饱和撞色 + 实心偏移阴影 + 88px 压缩字巨标题」的**海报 / 贴纸式**视觉，
改为「冷中性亮底 + 单一钢青 accent + 深色攻防拓扑态势台」的**SOC 示波台**视觉；
**功能、信息架构、业务逻辑、全部交互入口零删减**，只重写样式层、态势拓扑结构与一个纯呈现层反馈桥。

---

## 1. 设计方向（unslop 五线）

| 线 | 内容 |
|---|---|
| **Product** | 在隔离靶场里逐轮自适应探测 WAF、把每轮证据回溯成可打印报告的演示控制台，面向答辩与评审观众 |
| **Character** | 冷静 / 精密 / 可追溯 |
| **World** | 夜间安全运营中心（SOC）的示波台与网络拓扑图 |
| **Moments** | ① 监控页「攻防拓扑态势台」：攻击方 → 流量通道 → WAF 防线 → 目标，轮次节点按轮点亮，是全站唯一信息密集焦点；② 证据链「从 BLOCKED 到命中」的关键路径行 |
| **Signature** | 一条贯穿态势台的**有向流轨**（箭头 + 线型变化），只出现在态势区；状态灯用方形 / 菱形 / 斜纹 / 双框编码 |

**调和逻辑**：用户要「克制冷静 + 高对比 + 科技感」，`unslop` 要「chrome 安静、丰富只放进一两个内容时刻」。
两者交集 = 页面主体全部收敛为中性 hairline + 三档文字 + 单一 accent，把全部信息密度与色彩语义
集中到监控页的深色攻防拓扑台；状态区分由**形状 + 线型 + 文字**承担，颜色只是第二通道。

### 4.3 间距 / 形状

| 项 | 值 |
|---|---|
| 主栅格 | 4px（8 / 12 / 16 / 20 / 24 / 32 / 40 / 48）；紧凑控件允许 2px 微调档（22 / 26px） |
| 页面左右边距 | 32px（≤700px → 16px） |
| 卡片内边距 | 24px（表格卡 / 快照条按需 14–20px） |
| 控件内边距 | 8 / 12px；所有控件 `min-height:44px` |
| 组内 / 组间 / 区块间 | 8–12 / 16–24 / 32–48px |
| 顶栏 / 主导航 / 页脚 | 64 / 56 / 48+24px |
| 圆角 | 控件与内层 `--r-in:2px`；卡片与外层 `--r:4px`（近直角，嵌套相加）；无 pill |
| 阴影 | 仅 `0 1px 2px rgba(16,28,36,.04)` 中性软阴影；无偏移实心底 |
| 边框 | 1px hairline（主文字色 12% 透明度）；选中态 2px accent 下边线 |

### 4.4 动效规范

**统一缓动**：`cubic-bezier(.22,1,.36,1)`；**只转场** `color / background-color / border-color / opacity / transform /
stroke / stroke-dashoffset`（数据比例条 `width` 属数据可视化，按既有 QA 裁决保留）。
**不动画** `width / height / top / left / margin`（装饰层）；无 `transition-all`、无弹跳、无 `hover:scale` 放大。

| 时长 Token | 值 | 触发条件 |
|---|---|---|
| `--d-inst` | 140ms | hover / press / 切换 / 终端日志淡入 / 状态灯色与形状切换 |
| `--d-step` | 220ms | 轮次节点点亮、刻度轨、突触、输入框聚焦 |
| `--d-state` | 360ms | 状态转场、关键路径、防线、告警带、进度条、入场淡入（仅一次） |
| `refreshSweep` | 420ms · 1 次 | 任一指标数字变化 → 对应格底部下划线扫过（**非循环**） |
| `sitFlow` | 1.6s linear infinite | **仅** `data-phase="attack"` 且 `data-state="run"`：攻击流沿链推进 |
| `sitFlow` | 1.2s linear infinite | **仅** `.is-blocked`（拦截事件后 900ms 内）：拦截虚线通道推进 |
| `stateTick` | 1.4s ease infinite | **仅** `run` 态状态灯呼吸 |
| `spin` | 1s linear infinite | **仅** 加载中 spinner |
| `is-blocked` 保持 | 900ms | 拦截反馈类存活时长，到点自动移除 |
| `is-updated` 保持 | 460ms | 数据刷新类存活时长，到点自动移除 |

> 所有 `infinite` 动画都绑定**真实的进行中状态**（run / attack / loading / blocked），待机与终态一律静止；
> `prefers-reduced-motion:reduce` 下 `animation:none;transition:none`，但节点点亮、降级刻痕、
> 关键路径、防线满格、告警带、状态灯形状**以静态形态保留**，信息不丢。

## 5. 交互状态与数据更新时的界面表现

### 5.1 状态矩阵（形状 / 线型 / 文字 / 颜色四通道）

| 状态 | 触发条件 | 状态灯形状 | 颜色 | 拓扑与流轨 | 流状态文字 | 其他反馈 |
|---|---|---|---|---|---|---|
| **空状态 / 待机** `idle` | 进入监控页，无 cfg / 无 report / 无 pending | 空心方框 | 中性灰 | 8 节点全灭、流轨 `opacity:.12`、防线虚线、箭头暗 | `待命 · 无数据流` | 引导空态卡 + 「前往任务台」按钮 |
| **加载中** `loading` | `task.started` 后、`#dRound=0` | 实心方 + 1.4s 呼吸 | 钢青 | 攻击流半透明虚线、**不推进**、箭头暗 | `建立链路 · 等待首轮响应` | 方形 spinner、进度条 0%、thinking 提示 |
| **攻击发起** `attack` | `round.started` 写入 `#dRound>0` | 实心方 + 呼吸 | 钢青 | 攻击流 `8 6` 线型 1.6s 沿链推进、箭头亮、节点**逐轮点亮** | `ATTACK → WAF \| 轮次 N · 投递 N · 拦截 N · 命中 N` | 进度条随轮次、终端逐行日志淡入 |
| **拦截** `blocked` | `waf.blocked` 使 `#dBlocked` 增加 | 沿用 run 态 | 陶土 | 8 根防线竖线**由虚转实**（900ms）、拦截虚线通道 1.2s 流动 | 流量读数中「拦截 N」递增 | 对应指标格一次性下划线扫过、终端 warn 日志 |
| **命中** `hit` | `terminate_reason=HIT` 且无降级轮 | 实心方 + 内嵌横杠 | 灰绿 | 关键路径**贯穿**攻击方→目标 `opacity:.95`、命中通道粗实线、防线转实线、目标框转命中色、突触点亮 | `ATTACK → TARGET \| 命中路径已建立 · N 次命中` | `RUN COMPLETE · HIT`、报告 / 证据 / 历史生成 |

## 6. 攻防态势 / 数据流 / 布局主次

**四段拓扑**（`viewBox 0 0 1200 200`，`xMidYMid meet`，任何宽度下节点不变形）：

```
01 攻击方 ATTACKER      02 流量通道 TRAFFIC        03 WAF 防线 DEFENSE     04 目标 TARGET
[8 个方形轮次节点]  →   [攻击流 8-6 实线箭头]  →   [8 根防线竖线]      →   [目标方框]
[节点按 round_no 点亮]   [拦截 2-6 虚线]            [拦截时虚→实]
                         [命中 粗实线]              [命中时防线转实线]
                         [反馈环 + 神经突触]
────────────────── 命中关键路径（贯穿攻击方 → 目标，仅 hit / degraded 出现）──────────────────
```

- **攻防双方与节点关系**：左 = 攻击链按轮推进，中 = 反馈闭环与突触，右 = WAF 防线与目标；
  四段各有文字标签与 hairline 分区框，不靠颜色猜。
- **数据流向**：方向由箭头给出；路径由三条线型通道与关键路径给出；
  流量变化由 `已投递 / 已拦截 / 已命中` 数字 + 比例条 + 右下角实时流状态读数给出；
  节点状态由方形节点的空心 / 实心 / 斜纹给出。
- **装饰不干扰主次**：全页纯色底无网格；网格只在态势台内且极淡；所有拓扑装饰层
  `pointer-events:none`；态势台是全站唯一深色区与唯一信息密集焦点；
  导航 / 表单 / 表格 / 报告全部保持安静中性，只有一个 accent。

**信息架构与视线顺序（保持不变）**：顶栏（品牌 + 4 主流程 + 3 工具子页）→ 面包屑 → 页头
→ 任务配置 / 合规边界 → 会话指标 → 页脚；监控页为 配置快照 → 攻防态势台 → 运行面板。
7 个独立页面仍靠顶栏 `data-nav` 真翻页，不做下滑。
