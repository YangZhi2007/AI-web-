## 三、保留大写的边界（基因不动）

以下「仪器/档案刻度」类**保留大写**，它们是 SOC 卷宗风格的基因而非 slop：

- 状态枚举：`IDLE / RUNNING / NOT FOUND / DEGRADED / SIMULATED / CANCELLED / ERROR`、`IDLE` 态灯文字
- 编号与品牌：`PROBE / LAB`、`page-no` 页码、`stage-no` 区块编号、`SOUND OFF` 开关
- 档案定义行：`cfg-def__row dt`、`config-grid span`（`TARGET URL`、`VULN TYPE` 等）
- 卷宗内部：`rpt-kicker`、`rpt-sec h3 em` 等报告卷首刻度
