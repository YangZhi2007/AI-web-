# 重放脚本子页重设计说明（v0.26.0）

## 1. 重做理由

用户发来的截图是 `v0.24` 遗留的「复现包脚本内容」弹窗：一个 `about:blank` 窗口，把 `04-replay.sh` 原文倒进 `<pre>`。审计列出 8 处问题：

| 问题 | 位置 |
|---|---|
| 脱离产品：白底空窗口，无顶栏、无品牌、无返回路径 | 整个弹窗 |
| 40 行等宽原文一整块，无行号、无词法区分 | `<pre>` |
| 标题只有「复现包脚本内容」，没有任务 ID、包信息、状态 | 顶部 |
| 底部一句「可在隔离靶场环境中重放验证」是免责式说明，没讲两种模式 | 底部 |
| 不能复制、不能下载、不能回到工作台 | 全页 |
| 没有视觉记忆点，任何脚本查看器都长这样 | 全页 |
| 窄屏时脚本文字被压到不可读 | 移动端 |
| 不显示脚本属于哪个包、多少文件、多少字节 | 全页 |

上一轮 v0.25 把复现做成了页面内工作台，但「查看脚本」仍通向这个弹窗——演示动线在这里断了一次。本轮把它改成项目内第 8 个功能子页。

## 2. unslop 五线

- **产品**：把复现包里的重放脚本，做成靶场运维人员当场能读懂、能核对、能带走的离线执行说明页。
- **性格**：精确、克制、有实验室秩序感。
- **世界**：法医校验台 / 实验记录本——样本标签、步骤卡、指纹、封条。
- **记忆点**：① 执行路径 5 步卡，把 40 行 bash 压成可当场讲清的流程；② 底部档案封条（包名 + SHA-256 + 字节数）。
- **签名细节**：行号槽左侧的等宽刻度，与报告 01–05 编号刻度同源。

## 3. 页面结构

| 区 | 内容 |
|---|---|
| 顶栏 / 页头 | 复用项目 8 页共用顶栏，工具区新增「脚本」当前项；面包屑「控制台 → 证据链 → 重放脚本」 |
| PACKAGE / 复现包 | 任务 ID、六类文件计数、确认/证伪轮数、标注集；下方六类文件清单（含各自字节数） |
| FLOW / 执行路径 | 5 步：模式选择 → 文件就位 → 逐文件哈希 → 裁决断言 → 旁车校验；每步右侧 `Lxx` 是该步骤在脚本里的**真实行号** |
| SCRIPT / 重放脚本 | 逐行行号 + 七类词法着色（注释/字符串/变量/关键字/标识符/数字/运算符）；`pre-wrap` 长行换行，不横向溢出；35 行完整展示，无内部滚动截断 |
| 操作 | 复制脚本、下载 `.sh`、返回证据链；均为 44px 命中目标 |
| 档案封条 | 包名、截断 SHA-256（完整值见 `.sha256` 旁车）、整包字节数 |

空态不是通用占位：写明「在证据链页的复现工作台点『查看脚本』，或从报告页导出复现包后进入本页」，并给出返回入口。

## 4. 数据契约

`showReplay(pack)` 不再 `window.open('') + document.write`，改为：

1. 从 `pack.files` 取出 `04-replay.sh` 原文；
2. 把精简文档写入 `sessionStorage.probe.replayDoc`（包/哈希/字节/文件名清单/任务 ID/标注集/确认证伪数/脚本原文）；
3. `window.open(new URL('replay.html', location.href), '_blank')`；
4. 弹窗被浏览器拦截时**同页跳转**到 `replay.html`，不再退回白底脚本文本模态。

**不把 ZIP 字节写入 Store**——只传展示所需的精简文档，避免重复占用 sessionStorage 配额。页面渲染全部来自这份文档真值，`esc()` 转义后注入；脚本只展示不执行。

## 5. 语义边界

- 词法着色只区分代码角色，不改变脚本内容；专项用「渲染文本逐字拼回 == 原脚本」固定这一点。
- `Lxx` 行号由脚本内关键字实时定位，不是写死的装饰数字；找不到时显示 `L—`。
- 本页不执行任何命令、不发起任何请求。真实重放需使用者在授权隔离靶场内自行运行脚本。
- 六类文件的哈希在 v0.24/v0.25 已固定；本页是**阅读与携带**入口，不重复做完整性判定，判定仍由复现工作台给出。

## 6. 契约保持

- v0.25 `runReplay` 八项核对与工作台双态零回归；
