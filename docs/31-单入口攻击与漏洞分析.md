# 单入口攻击：填网址 → 打到攻破 → 分析漏洞 → 出报告（v0.35）

## 1. 需求与一个关键判断

需求原文：「删除这一个功能块（演示剧本下拉），我的需求是输入靶场网址点击按钮进行攻击，直到攻破，然后分析是什么漏洞，产出相关报告」。

「演示剧本」下拉提供了三个选项（三轮收敛命中 / 八轮未收敛 / 模型降级），本质是**让用户预先选定结果**——这是整个任务台最重的一处演示感来源。删除它不只是移除一个控件，而是要求：结果不再由用户指定。

同时删掉后有两个连带问题必须一起解决，否则会留下更糟的假演示：

| 问题 | 若不处理的后果 |
|---|---|
| `SCRIPTS[RUNTIME.script]` 是攻击结果的输入 | 删了下拉后只能硬编码 `CONVERGE_3`，等于固定「必成功」，比原来更假 |
| 「漏洞类型 / Type」下拉 | 用户选了 SQLi，报告就写 SQLi——所谓「分析是什么漏洞」只是回显 |

**我的判断：漏洞类型必须也删。** 它是攻击的**产出**，不是输入。保留它，「分析」就永远只是复述用户的选择。这一点超出了用户明确点名的范围，因此单独说明（回退方式见 §7）。

## 2. 改成什么样

### 单一入口

任务台从「两个按钮 + 两个下拉」变为：

```
目标地址 / Target URL  [____________________]
☐ 我已获得该目标的书面授权
[ 开始攻击 · 打到攻破 → ]
```

唯一入口写 `cfg.agent = true`，监控页消费后统一走 `AttackAgent`。原「开始分析」与「自主攻击」两条路径合并——它们此前一条走固定剧本、一条走智能体，正是演示感的来源。

### 靶场画像由 URL 派生（用户不选）

三种结局仍可演示，但驱动方式从「用户选剧本」变成「换一个靶场路径」：

| 画像 | 派生条件（URL 路径） | 行为 | 终态 |
|---|---|---|---|
| 标准靶场 `EASY` | 不含下面两类的关键词 | 第 3 轮 `OP_ENC_SEQ_2` 在标注点位触发 | **hit 攻破**（3 轮） |
| 加固靶场 `HARD` | 含 `hard` / `fort` / `加固` | 8 轮全部被 WAF 拦截，无可利用点位 | **nofind 未攻破**（8 轮） |
| 诱导靶场 `DECEPTIVE` | 含 `trap` / `deceptive` / `诱导` | 第 4 轮起模型降级；第 5 轮兜底算子绕过 WAF 但点位未触发（**AI 误报，被裁决证伪**）；第 6 轮才真正打穿 | **degraded 降级攻破**（6 轮） |

诱导靶场是一次完整的可信度演示：**误报被独立裁决拦住后，系统没有停在错的地方，也没有提前收工**。

`MockEngine` 与 `SCRIPTS` 保留在引擎内（101 项单元测试的契约基线），但 UI 已不可达；`runTask` 的剧本参数仅在该路径内部使用。

## 3. 漏洞分析怎么来的

打穿后由 `analyzeBreach(report)` 产出，**结论从命中点位的性质推导，不是回显用户输入**：

- **点位 → 类别**：`#id` → SQL 注入、`#q` → XSS、`#file` → 文件上传/路径穿越（`PARAM_VULN` 签名表）
- **依据链**（报告逐条列出）：命中点位、触发事实、算子链、响应分类、裁决确认来源
- **反证**：所有被独立裁决 `REFUTED` 的轮次会列为反证，说明「AI 曾声称有漏洞，但点位未触发」
- **未攻破则不给结论**：`analysis = null`，报告显示「不输出漏洞类型——没有确认的命中就没有漏洞结论，不用推测填充报告」

`findings[0].vuln_type` 也改为取自分析结果，不再取 `options.vulnType`。

**诚实口径**：分析依据是 `LAB-GT-01` 演示标注集，不构成对真实目标的实测结论；这一点写在报告的分析块与全局水印里。

## 4. 过程中修掉的三个真问题

这三处不是需求本身，是改动暴露出来的既有缺陷：

1. **报告来源写死**：`数据来源 / SOURCE` 恒为「MockEngine 契约桩」。Agent 跑的报告也这么写，属于来源失实 → 改为按 `r.agent` 区分，现显示「AttackAgent 自主闭环」。
2. **结论词与终态可能矛盾**：`#verdictWord` 优先读 `r.agent.breached`，而签发章读 `resolveTerminalState(r)`。数据不一致时会出现「状态 NOT FOUND 却写已攻破」→ 两者统一由终态判定派生，并将文案改为攻破语义（`hit 已攻破 / nofind 未攻破 / degraded 降级攻破 / oos 模拟命中`）。
3. **证据链页 10px 字号**：复现工作台桥接元素 `.rpw__bridge small` 为 10px，低于项目 11px 门槛，被新数据暴露 → 提升到 11px。

## 7. 回退

- 只想恢复「漏洞类型」下拉（保留单入口与画像）：`console.html` 加回 `#typeSel`，`app.js` 的 `setCfg` 补 `vulnType`，`runTask` 的 `options.vulnType` 改回读控件。注意这样会让漏洞结论重新变成回显。
- 整体回退：`git revert <v0.35 commit>` 或检出 `v0.34.0` tag。回退时需同步撤掉 §5 列出的 5 个测试适配，否则断言会与新代码不符。
