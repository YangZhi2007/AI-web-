# v0.33 · 幻觉模块拆分为独立后端看板

## 为什么改

此前（v0.27–v0.32）幻觉模块是「第二个大功能区」，与智能绕过系统共用顶栏、系统切换控件、`console.css` 皮肤与页脚互链。用户明确定位：**它是一个后端看板，不该融合到功能页面**。因此本轮做结构性拆分，两套系统物理独立、互不引用。

## 拆分结果

### 目录
```
webapp/
├─ index.html / console.html / monitor.html ...   ← 绕过系统（功能页）
├─ js/ css/                                        ← 绕过系统资源
└─ hf/                                             ← 独立后端看板
   ├─ index.html  probe.html  sample.html
   ├─ truth.html  evidence.html  repair.html
   ├─ version.html  eval.html  report.html
   ├─ js/engine.js  js/app.js
   └─ css/hf.css
```

- 9 个页面用 `git mv` 迁入（保留历史），文件名去 `hf_` 前缀。
- `js/hf.js` → `hf/js/engine.js`、`js/hf-app.js` → `hf/js/app.js`。
- 旧 `css/hf.css`、`css/hf-app.css` 删除，由 `hf/css/hf.css` 取代。

### 看板壳（侧边栏）
- 左侧 248px 固定侧栏：品牌 `HF / LAB` + 三分组导航（监测与评测 / 数据资产 / 记录与输出）+ 底部状态（标注集、引擎版本、外联）。
- 右侧内容区：面包屑 + 标题 + 副标题 + 右上角元信息（标注集 / 引擎 / 外联）。
- `<900px` 侧栏转为顶部横向滚动导航，`<700px` 读数带两列堆叠。

### 视觉调性（unslop 方向：看板冷静底 + 双轨强调）
- 中性石墨 ramp（`#F3F4F2` 底 / `#FFFFFF` 卡 / 灰 hairline），不再用功能页的偏黄绿浅底。
- 酸柠只作单一强调：品牌 mark、当前菜单、主按钮、关键数字。
- 语义色只落在数据上：深青绿 `#0B6E60` 表示 RAG / 一致 / 正向，深红 `#B0232F` 表示幻觉 / 告警。
- **双轨 signature 保留**：每个结论成对出现（base 灰 / RAG 青绿），仍是看板最核心的识别点。
- 弃用高饱和撞色与 pill 堆叠；按钮/输入统一 44px 命中、8px 控制圆角、12px 卡片圆角。

### 解耦
- `core.js` 移除 `injectSysSwitch()`；`core.css` 移除 `.sys-switch` 全部样式（死代码）。
- 绕过系统 9 个页面确认：`sys-switch=0`、幻觉互链 `0`。
- `about.html` 的「两个大功能区」段落改为「与本控制台分离的后端看板」，页脚移除幻觉入口。
- 看板 9 页无任何指向 `../index.html` 等绕过系统页的链接。

## 过程中修掉的问题
- `hf/css/hf.css` 首版 `--line-2` 后漏冒号，导致两条 hairline 变量失效，已修。
- 解耦验收脚本自身两处 bug：①模板字符串内含 `/` 的正则字面量被提前终止导致求值异常；②看板内部 `index.html` 短链被误判为跨系统互链。均已修正（改用字符串判断 + 只认 `../` 开头链接）。
