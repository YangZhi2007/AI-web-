## 过程中修复的真 bug

**CSS 注释提前闭合（旧坑复现）**：`hf.css` 与 `hf-app.css` 头部注释写了 `.card/.grid-*/.page-head/`，其中 `grid-*` 后的 `/` 与 `*` 构成 `*/`，提前闭合注释，导致紧随的 `.hf-metrics` 规则被吞——首页指标带一直显示 3 列（console.css 的 `.metrics` 默认）而非设计的 4 列。用 CDP 枚举 `document.styleSheets` 匹配规则，发现只有 `.metrics{repeat(3)}` 命中、`.hf-metrics` 从未解析，定位到注释。改为顿号分隔后指标带恢复 4 列。

这与项目记忆里 `data-*/aria-*` 是同一类坑，已再次确认。全项目 CSS 注释配对扫描现为 0 异常。

另修证据库成因标签宽度 88px 导致「推理逻辑缺陷」折行，调整为 110px + nowrap。
