# 17 · 自主攻击智能体闭环（方向澄清与落地，2026-11-15）

> 触发：用户澄清「我的意思是：把一个网址丢进去，然后进行持续攻击，智能体自动攻击靶场，直到攻破为止，然后生成相关报告」。
> **方向判定**：v0.22 把项目做成「验证辅助 / 可信度裁决」是偏了。本轮按用户原始意图把产品主叙事改回**自主攻击智能体闭环**，v0.22 的独立裁决不废弃，而是成为闭环的**攻破判据**。
> 版本基线：`v0.23.0`。

---

## 0. 一句话交付

任务台现在有一个主入口：**填目标网址 → 勾选授权 → 点「自主攻击」→ 智能体自己一轮轮打 → 点位被独立确认即判攻破并停机 → 自动生成含逐轮决策依据的报告**。三剧本固定演示仍保留为对照入口，两条路径共用同一套事件流、状态机、报告与跨页持久化。

## 1. 需求还原与实现对照

| 用户原话 | 落地结果 |
|---|---|
| 把一个网址丢进去 | 任务台 `#urlInput` 输入任意合法 URL；提交前必须勾选书面授权；靶场强度由路径派生，不需要额外选参数 |
| 进行持续攻击 | `AttackAgent.analyze()` 是 `for` 迭代循环，不是遍历预定义轮次列表；每轮 `planNextRound()` 依据上一轮 WAF 拦截特征与已试算子集合实时选下一个算子 |
| 智能体自动攻击靶场 | 8 个算子编号白名单（只含编号、不含载荷文本）；响应由靶场规则模拟；决策理由逐轮写进 `agent_decision` / `agent_observed` |
| 直到攻破为止 | **攻破 = 独立裁决 `CONFIRMED`（标注点位真的被触发）**，不是「WAF 没拦住」；达到即 `break` 停机。模型把响应异常当成攻破会被判 `REFUTED` 并**继续迭代**，不提前收工 |
| 然后生成相关报告 | 自动写 `Store.report`，报告卷首改为「已攻破 / 未攻破」，02 新增自主攻击闭环摘要（终止条件 / 攻破轮 / 迭代轮次 / 算子白名单）+ 逐轮决策链；5 附录、导出 PDF、打印黑白全部保持 |

### 为什么不是「无限攻击」
任何真实智能体都必须有停止条件，否则是死循环而非闭环。本实现有三个，且都如实写进报告：

1. **攻破即停**——点位被独立确认，目的达成，立即终止；
2. **预算耗尽**——`MAX_ROUNDS`（轮次上限）=8 轮内未攻破，如实记「未攻破」，不刷成成功、不无限重试；
3. **越界终止**——目标不在授权白名单，仅 3 轮纯模拟即停，声明不构成任何真实结论。

答辩时把这三条件主动说出来，比被问出来好：它正好回答「会不会失控」「凭什么停」两个必问点。

## 2. 合规边界（不可省略，答辩必须主动讲）

- **仅授权靶场**：`scopeOK()` 白名单仍是 `localhost / 127.0.0.1 / ::1 / lab / lab.local / lab-target-01`；输入其它域名一律走纯模拟分支，授权 ID 置空、每轮裁决 `NOT_APPLICABLE`（不适用），报告写 `OOS_NOTICE`（越界声明）。
- **零外部请求**：全部由 `MockEngine` 契约桩驱动，`mock_flag=true`（演示数据标记）全程保留，不发起任何真实网络请求；验收断言外部请求数为 0。
- **不涉及未授权目标、不产出真实攻击能力**：算子白名单只含编号，没有载荷文本、没有真实利用链；`HttpEngine.analyze()` 仍是未接入桩。
- **书面授权闸门**：未勾选授权时按钮禁用 + 事件层二次拦截，两项都写进专项验收。
- **诚信标注**：报告与证据链页保留「演示数据 · 非实时推理 · 零外部请求」「不构成实测误报率」等既有标注。

> 因此本轮实现的是**授权靶场内的模拟自主攻击闭环**，不是对任意真实站点的自动化攻击工具。要接真实靶场，见 §8「仍未做」。

## 3. 引擎实现（`webapp/js/console.js`）

- `AGENT_OPS`：8 个算子编号，每个带 `avoids`（能避开哪条 WAF 规则）与 `note`（中文说明）。
- `AGENT_PROFILES` / `agentProfileOf(url)`：三种靶场强度由目标路径派生——
  `/lab/sqli_01.php` 标准靶场（可攻破）、`/lab/hard.php` 加固靶场（打不穿）、`/lab/trap.php` 诱导靶场（模型误判后继续迭代）。仍是「丢一个网址」一个动作。
- `planNextRound(history, profile, no)`：反馈驱动决策——优先挑「能避开上轮拦截特征」且未试过的算子；降级轮只用兜底集合；算子用尽则循环复用。返回决策理由，逐轮可核对。
- `agentResponse()`：模拟靶场响应，只有标注点位触发的算子算攻破；`trapOp` 会绕过 WAF 但不触发点位。
- `AttackAgent.analyze()`：状态驱动循环，复用既有 `onEvent` 事件流（`task.started / round.started / payload.generated / request.sent / waf.blocked / verdict.ready / degraded / task.terminated`），因此监控页拓扑、刻度轨、仪表数字、遥测桥全部自动同步。
- `report.agent`：`breached / breachRound / stopReason / budget / used / decisions[]`，只增字段不改语义；`report.credibility`（独立裁决计数）与 v0.22 双通道字段在 Agent 路径同样生成。
- `runTask(opts)` 新增 `o.agent` 分支选择 `AttackAgent`，默认仍走 `AnalysisEngine`（三剧本）。**既有 101/62/51/22/49 全套验收零回归**。

### 触发契约（v0.17.2 的一次性意图模型不变）
任务台点击「自主攻击」→ `Store.setCfg({..., agent:true})` + `Store.setPendingRun()` → 监控页读即清除并消费 → 只执行一次。浏览、刷新、后退、跨页导航一律不触发；`cfg.agent` 残留只是快照，不是执行开关。

## 5. 四档真实跑出来的结果（不是编的数字）

| 靶场 | 轮次 | 终态 | 攻破 | 裁决序列要点 | 停止原因 |
|---|---|---|---|---|---|
| 标准 `sqli_01.php` | 3 | `hit` | **是，R03** | 拦截 → 拦截 → 确认命中 | `BREACH`（攻破即停） |
| 加固 `hard.php` | 8 | `nofind` | 否 | 8 轮全 `TRUE_NEGATIVE`（拦截未触发） | `BUDGET_EXHAUSTED` |
| 诱导 `trap.php` | 8 | `nofind` | 否 | R06 模型声称命中但点位未触发 → `REFUTED`（证伪），R04/R05/R07/R08 降级不确认 | `BUDGET_EXHAUSTED` |
| 越界 `example.com` | 3 | `oos` | 否 | 3 轮全 `NOT_APPLICABLE` | `OUT_OF_SCOPE`（纯模拟） |

标准靶场的决策因果链：`R1 OP_BASE`（建立基线）→ 上轮 `RULE_KEYWORD_A`（规则关键字 A）→ `R2 OP_ENC_SEQ_1`（避开 A）→ 上轮 `RULE_KEYWORD_B`（规则关键字 B）→ `R3 OP_ENC_SEQ_2`（避开 B，点位触发）→ 攻破。每一步都由上一轮响应决定，不是预定义序列。

## 8. 仍未做（讲稿里必须说「未做」）

1. **真实靶场接入**：`HttpEngine.analyze()` 仍是未接入桩，当前闭环是本地契约桩模拟，不具备对真实站点或真实靶场发包的能力。
2. **真实 oracle（确定性验证器）**：`LAB-GT-01` 与 `AGENT/*` 都是演示标注，不是靶场服务端状态断言。
3. **无限迭代**：不存在也不打算实现；任何真实系统都需停止条件。
4. **误报率量化 / 自建靶场点位集 / 与纯规则基线的对照实验**：仍是 `docs/00` §6.9 的 P1 待做项，本轮未推进。
5. **申报书 / PPT 口径同步**：见 §6，属于材料工作，本轮只给出建议表述与冲突清单，未改动申报书文件。
