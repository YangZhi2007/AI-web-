## 0. 一句话定位（申报书 / PPT 首页 / 开场白统一用这一句）

> 本系统是面向**授权靶场**的自主迭代探测智能体：输入目标后，智能体依据每轮 WAF 响应自适应选择探测算子并持续迭代，以**可独立核对的点位触发**作为攻破判据，攻破即停、未攻破如实终止，并自动生成含逐轮决策依据与证据链的留痕报告。
> 演示期由本地契约桩驱动，零外部请求、不涉及未知漏洞挖掘、不用于未授权目标。

**口语版（30 秒）**：「给一个网址，智能体自己一轮轮试；每轮换什么策略由上一轮 WAF 的拦截特征决定。但 WAF 没拦住不等于漏洞成立——只有当标注点位真的被独立确认，我们才判攻破并停机；打不穿就如实记未攻破，然后把每一轮为什么这么选写进报告。」

### 用词替换（现场必须守）
| 不要说 | 改成 |
|---|---|
| AI 自动挖洞 / 发现 0day / 超越 sqlmap | 授权靶场内的自主迭代探测 / 已知点位验证 |
| 无限攻击直到拿下站点 | 攻破即停 / 有界停止（攻破、预算耗尽、越界） |
| 已验证真实站点漏洞 / 降低误报率 X% | 演示数据 / 判定依据可回溯、失败如实标记 |
| 模型说命中就是命中 | 模型结论是「声称」，攻破由独立裁决确认 |
| 全链路自动化攻击 | 输入 → 迭代 → 判定 → 报告的信息闭环 |

## 1. 现场准备

- 直接用浏览器打开 `webapp/index.html`（`file://` 可运行，无需服务器、无需联网、零外部请求）。
- 主页点「进入控制台」到 `webapp/console.html`；顶栏四项真翻页（任务台 / 运行监控 / 证据链 / 报告），右侧三个子页面（配置 / 历史 / 说明）。
- **默认目标** `http://127.0.0.1/lab/sqli_01.php`（标准靶场，3 轮攻破）；换路径即可演示其它结局，不用改代码：
  - `/lab/hard.php` → 加固靶场，8 轮打不穿；
  - `/lab/trap.php` → 诱导靶场，模型误判被证伪后继续迭代；
  - 任意非白名单域名（如 `https://example.com/x`）→ 越界纯模拟。
- 每次提交前**必须勾选书面授权**，否则两个入口都禁用。

## 2. 五分钟动线（逐句讲稿）

| 时间 | 操作 | 讲什么 | 评委看到什么 |
|---|---|---|---|
| 0:00–0:30 | 主页 → 任务台 | 「我们只输入一个网址，不调任何参数。靶场强度由目标路径决定，勾选书面授权。」 | 表单只有目标地址 / 漏洞类型 / 剧本；主按钮「自主攻击 · 打到攻破」 |
| 0:30–1:30 | 点「自主攻击」→ 自动翻到运行监控 | 「智能体开始自己打。每轮换哪个算子不是预先排好的，是看上一轮 WAF 拦截特征实时选的。」 | 拓扑逐轮点亮；**智能体决策流**逐行追加：上轮观测 → 本轮算子 → 响应 → 独立裁决 → 继续 |
| 1:30–2:00 | 指决策流三行 | 「R1 建立基线被规则 A 拦；R2 就选避开 A 的算子，又被规则 B 拦；R3 选避开 B 的算子，点位被独立确认，攻破停机。」 | 状态条「已攻破 · 停机 R03」，攻破行浅底 + 文字「攻破 · 终止」 |
| 2:00–2:45 | 进报告页 | 「报告自动生成。卷首是已攻破，02 有闭环摘要和逐轮决策链；5 个附录含逐轮记录、模型决策原文、配置快照，可导出 PDF。」 | 卷首「已攻破」、4 读数（攻破即停 / R03 / 3/8 / 8 个编号）、决策链、独立裁决盒 |
| 2:45–3:45 | 回任务台，把地址改成 `/lab/trap.php` 再跑一次 | 「这一档最关键：第 6 轮模型以为攻破了，独立裁决说点位根本没触发，判证伪。智能体不会被模型骗停，继续打到预算耗尽，报告如实写未攻破。」 | 决策流 R06 标「证伪」且下一行仍是「继续」；报告卷首「未攻破」、终止条件「预算耗尽」 |
| 3:45–4:30 | 证据链页 | 「双轨对照：上轨模型的声称，下轨点位标注的裁决，错位的格子就是要人工复核的分歧轮；明细表给出具体理由。」 | 8 格双轨、错位刻痕、待复核明细表、结论优先级提示 |
| 4:30–5:00 | 换成非白名单域名跑一次（或直接讲） | 「越界目标一律纯模拟：不发请求、授权 ID 置空、裁决全不适用、明确声明不构成真实结论。这是硬边界。」 | 状态条「越界 · 纯模拟」，报告 `OOS` 声明 |

> 现场若时间紧，只做 0:00–2:45 + 2:45–3:45 两段：一次干净攻破、一次误判续攻，已经把闭环、攻破判据和诚实终止全讲完。

## 3. 评委追问 8 问（答法 + 可指的页面）

| # | 追问 | 答法 | 指向 |
|---|---|---|---|
| 1 | 和市面 AI 自动挖洞 / 扫描器有什么区别 | 目标函数不同：别家优化绕过成功率，我们的攻破判据是点位被独立确认；模型结论只是「声称」，会被裁决证伪 | 证据链页双轨 / 报告 02 独立裁决盒 |
| 2 | 「持续攻击」会不会失控 | 三个显式停止条件：攻破即停、8 轮预算耗尽如实终止、越界纯模拟；不做无限重试 | 任务台说明 / 报告 02 终止条件 / `docs/17` §1 |
| 3 | 凭什么是 8 次 | 8 是固定预算的实验控制变量，不是收敛判据；报告 8 格刻度展示实际用量与信息增益轮，打不穿时不刷成成功 | 配置页冻结常量只读投影 / 报告 02 轮次预算 |
| 4 | 算子是不是写死的剧本 | 每轮 `planNextRound()` 读上一轮拦截特征与已试集合实时选，决策理由逐轮留痕；换靶场路径会得到不同轮数与结局 | 运行监控决策流 / 报告 02 决策链 |
| 5 | 模型自证 `validation:PASSED` 算不算验证 | 不算。那是模型原文里的自证，裁决不读它、也不读置信度，只看点位标注 | 报告附录 B 原文 / 02 诚信标注 |
| 6 | 误报率降低了多少 | 不能报数。当前只做到「误报可定位、可计数、可复核」；标注集与基线对照实验未做 | `docs/17` §8 / `docs/00` §6.9 |
| 7 | 能不能打真实站点 | 不能，也不打算在演示期做。仅 `scopeOK()` 授权靶场白名单内模拟，越界零请求；`HttpEngine` 仍是未接入桩 | 说明页「使用边界」 / 越界演示 |
| 8 | 数据是不是编的 | 是演示数据，`mock_flag=true` 全程保留、零外部请求；但**逻辑不是编的**——决策、裁决、终止都由代码实时执行，报告字段可逐轮核对 | 报告 5 附录 / 专项验收脚本 |

## 4. 能说 / 不能说（合规底线）

**能说**：授权靶场、自主迭代探测、攻破即停、有界停止、独立裁决、逐轮决策依据、证据链留痕、演示数据、零外部请求。

**不能说**：自动攻击真实站点、无限攻击直到拿下、发现未知漏洞、已验证真实站点漏洞、降低误报率 X%、已接入真实靶场、全链路自动化攻击。

**必须主动说（比被问出来好）**：当前是本地契约桩模拟闭环；真实靶场接入、真实验证器、误报率量化、自建靶场点位集、按验证器置信度提前终止均**未做**；算子白名单只含编号、不含载荷文本。

## 7. 现场故障预案

| 现象 | 处理 |
|---|---|
| 打开报告/证据页显示空态 | 会话里还没有报告，回任务台跑一次；`sessionStorage` 存最近一次报告，刷新浏览器即空 |
| 按钮灰掉点不动 | 未勾选书面授权，勾选后两个入口同时解禁 |
| 想切结局但忘记路径 | 标准 `sqli_01.php` / 加固 `hard.php` / 诱导 `trap.php`；非白名单域名 = 越界 |
| 打印时 JSON 附录丢失 | 导出按钮与 `Ctrl+P` 都会自动展开 `details.raw`；报告只输出 `#report` 的 5 附录 |
| 想回到旧的固定剧本演示 | 任务台点「开始分析」（不是「自主攻击」），三剧本路径完整保留、验收零回归 |
