# 漏洞复现功能重设计 · 复现工作台（v0.25.0）

> 本轮是**重做**，不是换皮。v0.24 的 F-04 只做到「导出 ZIP + 弹窗贴重放脚本文本」，评审在现场看不到任何复现过程。本轮把它改成页面内可交互的复现工作台。需求边界仍以《AI漏洞智能探测系统新增功能需求说明书》§4.4 / 表 9 / §7.2 / §10.2 场景四为准。

## 1. 为什么要重做

审计 v0.24 的三处实质缺陷：

| 缺陷 | 表现 | 本轮处理 |
|---|---|---|
| 「重放」不是演示，是贴文本 | 点「查看重放」开新窗口显示 `.sh` 脚本文本，评委看不到结果 | 改为页面内逐项真实重算 + 判定章 |
| 导出被当成主功能 | 工具条上「导出复现包」与 PDF 并列，复现卡只有两个小按钮 | 导出降为工作台内次要动作，主按钮是「开始复现」 |
| 无失败态 | 只展示可导出，无法演示"包被替换/结论被篡改"时系统能发现 | 新增不一致分支，精确定位不符项 |

需求 §10.2 场景四写的是「导出命中记录证据包并在靶场重放，重放结果与核验结论一致」。v0.24 只能导出，不能当场展示"一致"；本轮补上后半句。

## 2. 方向（unslop 五线）

- **产品**：把一次命中的探测结论，变成评审当场能「重放 → 逐项核对 → 确认一致」的证据台。
- **性格**：精确、可核对、有实验室秩序感。
- **世界**：法医实验室 / 校验台——样本、对照、指纹、逐项比对。
- **记忆点**：复现工作台的**原始结论 / 重放实测双栏**与**八项逐项核对表**；一致时两值合并显示一次并打 `≡` 刻度，不符时并列「原 x / 重 y」并打 `✕`。
- **签名细节**：桥接列的 `≡` 等宽符号，以及判定章里的标注集与通过计数，贯穿台账与截图。

一个亮元素：复现判定章（绿色一致 / 红色不一致）。其余读数、表格、按钮保持安静。

## 3. 功能结构

证据链页 `#resultCard` 顶部的工作台，按阅读顺序：

1. **结论对照双栏**：左「原始结论 / REPORTED」显示任务编号、命中轮、独立裁决、标注集；右「重放实测 / REPLAYED」初始为占位，复现后回填真实重算值；中间桥接列 `≡ 逐项重算`。
2. **动作区**：主按钮「开始复现 →」，次按钮「导出证据包」「重放脚本」。不可复现时整块不渲染动作，只显示原因。
3. **逐项核对表**：八项，每项含编号、中文标签、期望值、实测值、形状刻度、文字判定。
   - F01–F05：五类原料文件的 SHA-256 重算，与声明摘要逐文件比对。
   - F06：核验摘要自身——它内含前五类哈希，自身哈希写进去会形成自引用循环，故标「旁车校验」，由同名 `.sha256` 文件负责完整性（继承 v0.24 决策）。
   - R03：命中轮独立裁决重放，只喂 `ai_claim` + 标注事实 + 降级/越界上下文，不读 `verdict`、置信度或模型原文自证。
   - C01：确认轮数汇总，重算数 vs 声明数。
4. **判定章**：`复现一致` / `复现不一致` + 「N / 8 项通过 · LAB-GT-01」。形状章随结论切换（勾 / 叉），颜色只作辅助。

## 4. 复现引擎 `runReplay(report, declaredOverride)`

纯函数，同步，零副作用：

- 不播放预设动画——每一项都用当前 report 的原始字段重新计算，再与声明值比对。
- `declaredOverride` 可传入已导出包的原始摘要，用于检验文件是否被替换；不传则用当前 report 生成的摘要做自检。两条路径共用同一判定，没有分支特判。
- 门禁沿用 v0.24：只有独立裁决 `CONFIRMED` 且点位触发的轮次能进入复现。被改成未触发的轮次会直接返回「无独立裁决确认的命中轮次」，不伪造复现。
- 返回 `{ok, pass, checks, hit, label_set, base, hitRounds}`；UI 层只做渲染与逐行推进，不参与判定。

**一个重要的语义边界**：若声明值随当前数据一起重算（不传 `declaredOverride`），系统只能自检内部一致性；要发现"包被替换"，必须用导出时留下的原始摘要或 `.sha256` 旁车。这一点在专项里用篡改用例固定下来，讲稿里也要如实说明。

## 5. 视觉与响应式

- 双栏在窄屏（≤700px）改为纵向堆叠，桥接列转为横排；核对行在窄屏把值换到第二行，不压缩成不可读的短片段。
- 一致行的期望值与实测值合并显示一次，减少重复；不符行才并列两值并分别用告警/确认语义色。
- 逐行进入用 90ms 递进的短位移淡入；`prefers-reduced-motion` 下一次性渲染全部，不做动画。
- 打印段继承 v0.24 的 `.repro-evidence{display:none}`，工作台是它的子元素，整块不出现在 PDF 里。
